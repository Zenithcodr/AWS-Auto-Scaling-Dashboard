Cloud + DevOps Toolchain

Project layers matched to the AWS Auto-Scaling Tools deck
Local Docker • AWS APIs • CSV/SQLite • IaC
01 Local Dashboard

Python, Flask, Gunicorn, HTML, CSS, JavaScript, Chart.js, and Docker Compose run on your Mac.

02 AWS + APIs

boto3 connects the local dashboard to EC2, Application Load Balancer, Auto Scaling Group, CloudWatch, IAM, and optional S3 archival.

03 Data + Analytics

Metric snapshots and audit events are retained in CSV and SQLite for history, reports, and future automation.

04 DevOps + IaC

Terraform creates AWS resources, Ansible configures the workload target, and Docker keeps the dashboard local.
